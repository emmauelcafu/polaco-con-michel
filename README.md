# 🇵🇱 Polaco con Michel

Aplicación para aprender polaco desde el español. Vocabulario para mamá y futura matrona, tarjetas, lectura, ejercicios de escucha y progreso local.

Proyecto estático: `index.html`, `data.js`, `app.js`, `manifest.webmanifest`, `icon.svg`.

El audio depende de la voz polaca del dispositivo. Los avances se almacenan en el navegador, no en GitHub.
